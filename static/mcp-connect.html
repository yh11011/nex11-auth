用 Codex／ChatGPT 訂 NexAlarm 鬧鐘

此功能限 NexAlarm Premium。先在所有要響鈴的手機安裝新版 App、登入同一個帳號並連網，再連接 AI 助手。你的密碼只輸入在 NexAlarm 登入與授權頁。

MCP 網址：https://login.nex11.me/mcp

Codex

codex mcp add nexalarm --url https://login.nex11.me/mcp
codex mcp login nexalarm

在瀏覽器登入 NexAlarm 並授權讀取與管理鬧鐘。完成後重新開啟對話，請 Codex 設定鬧鐘。

ChatGPT 私人連接

不需要在 GPT Store 登錄或公開上架。若帳號與工作區允許自訂 MCP，先啟用 Developer mode，再在 Plugins 按「＋」新增連接，貼上下列欄位並選擇 OAuth。

開啟 ChatGPT Plugins

此按鈕開啟 Plugins 頁面；目前 OpenAI 沒有公布可預填任意 MCP 名稱與網址的連結，因此仍需按「＋」並貼上欄位。建立後登入 NexAlarm 授權，即可在支援的對話中使用。

若沒有自訂連接選項，請使用上方 Codex 指令。

試用指令

  • 下週三早上七點叫我起床。
  • 每週一到五七點半設定「上班」。
  • 列出鬧鐘，關閉剛建立的上班鬧鐘。
  • 查詢剛剛那個鬧鐘哪些手機已排程。

確認手機收到

同一鬧鐘依各手機當地時間響。AI 會列出已排程、非精確排程、待接收或失敗的手機；待接收不代表成功。離線、被強制停止或舊版手機無法保證即時收到，請開啟新版 App 再查詢。

指定日期已過時會回報失敗，不會自動改到隔天。時區變更後以手機新時區排程。

解除授權

在 NexAlarm 的設定 → AI 整合中解除指定助手授權，也可以從 AI 平台移除連接。已排程鬧鐘會繼續響。
